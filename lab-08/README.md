# MAKHNYK DANIIL — Адаптивний лендинг бренду одягу з формою зворотного зв’язку

Вебсайт локального бренду свідомого одягу **MAKHNYK DANIIL** з інтерактивним помічником підбору розміру (**AI Size Assistant**) та адаптивною формою зворотного зв’язку з клієнтською валідацією.

## Технології
- **HTML5** — семантична розмітка, ARIA-атрибути доступності (`aria-invalid`, `aria-describedby`, `role="alert"`).
- **Tailwind CSS** — адаптивна *mobile-first* верстка (`grid-cols-1 md:grid-cols-2`), інтерактивні стани (`focus-visible`, `hover`) та візуальні стани полів (`Normal`, `Focus`, `Error`, `Success`).
- **Vanilla JavaScript** — модульна валідація полів, регулярні вирази (RegEx), динамічна перевірка (`blur`, `input`, `submit`), обробка граничних випадків (Edge Cases) та керування модальним вікном.

## Реалізований функціонал форми
- Перевірка обов'язкових полів:
  - **Ім'я**: мінімум 2 символи.
  - **Електронна пошта**: валідація формату `user@domain.com`.
  - **Номер телефону**: суворий формат `+380XXXXXXXXX` + UX-підказка для швидкого перетворення номерів вигляду `0XXXXXXXXX`.
  - **Повідомлення**: мінімум 10 символів із підрахунком введених символів при помилці.
  - **Згода з політикою конфіденційності**: обов'язкова активація чекбокса.
- Доступне модальне вікно імітації успішного надсилання з підтримкою закриття клавішею `Escape` та поверненням фокусу.
